# Security reporting

Do not post credentials, private games, databases, checkpoints or private replay
archives to public issues. Report a minimal synthetic reproduction and affected
binary/content versions through the repository's private vulnerability reporting
channel once the maintainers enable it.

A named private reporting destination and supported release window must be
established before public release. They are tracked as release blockers in
[readiness](docs/readiness.md). No email address or response-time promise is
invented by this preparation work.
